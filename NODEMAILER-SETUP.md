# Nodemailer Setup Guide

## Overview
The application form sends emails to `info@cuhvet.com` using Gmail SMTP via nodemailer.

## Environment Variables Required

Create a `.env.local` file in the root directory with these variables:

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-gmail@gmail.com
SMTP_PASSWORD=your-16-character-app-password
EMAIL_TO=info@cuhvet.com
```

## Gmail SMTP Setup - Step by Step

### Step 1: Enable 2-Step Verification
1. Go to your Google Account: https://myaccount.google.com/security
2. Click on "2-Step Verification"
3. Follow the prompts to enable it (you'll need your phone)
4. Complete the setup

### Step 2: Generate App Password
1. After 2FA is enabled, go to: https://myaccount.google.com/apppasswords
2. You might need to sign in again
3. In the "Select app" dropdown, choose **"Mail"**
4. In the "Select device" dropdown, choose **"Other (Custom name)"**
5. Type: **"Cuhvet Website"**
6. Click **"Generate"**
7. Google will show you a 16-character password like: `abcd efgh ijkl mnop`
8. **IMPORTANT**: Copy this password and remove all spaces
9. Use it as `SMTP_PASSWORD` in your `.env.local`

### Step 3: Configure .env.local
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=youremail@gmail.com
SMTP_PASSWORD=abcdefghijklmnop
EMAIL_TO=info@cuhvet.com
```

**Example with real values:**
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=contact@gmail.com
SMTP_PASSWORD=xyzw abcd efgh ijkl
EMAIL_TO=info@cuhvet.com
```

### Understanding the SMTP Settings

- **SMTP_HOST**: `smtp.gmail.com` - Gmail's SMTP server
- **SMTP_PORT**: `587` - Standard port for TLS/STARTTLS (recommended)
  - Alternative: `465` for SSL (requires `secure: true` in code)
  - Alternative: `25` (often blocked by ISPs)
- **SMTP_USER**: Your full Gmail address
- **SMTP_PASSWORD**: The 16-character App Password (NOT your Gmail password)
- **EMAIL_TO**: Where to send the applications (`info@cuhvet.com`)

## Email Flow

1. User fills out the application form on the website
2. Form data is sent to `/api/submit-application` endpoint
3. API route uses nodemailer to connect to Gmail SMTP server
4. Email is sent FROM: `SMTP_USER` (your Gmail account)
5. Email is sent TO: `EMAIL_TO` (info@cuhvet.com)
6. User sees success message on the website

## Why Use App Password Instead of Regular Password?

Google requires App Passwords for security when third-party apps access Gmail. Your regular Gmail password won't work with SMTP. App Passwords are:
- 16 characters long
- Randomly generated by Google
- Specific to one app/device
- Can be revoked without changing your main password
- More secure than using your actual password

## Troubleshooting

### "Invalid login" or "Authentication failed"
- Make sure 2-Step Verification is enabled
- Verify you're using the App Password, not your Gmail password
- Check that there are no spaces in the App Password
- Ensure `SMTP_USER` is your full Gmail address

### "Connection timeout"
- Check your internet connection
- Try port `465` with `secure: true` instead of `587`
- Some networks block SMTP ports - try a different network

### Email not arriving at info@cuhvet.com
- Check spam/junk folder
- Verify `info@cuhvet.com` email exists and is active
- Check Gmail "Sent" folder to confirm email was sent
- Wait a few minutes (sometimes delayed)

### "Missing credentials"
- Ensure `.env.local` file exists in the root directory
- Restart your dev server after creating/updating `.env.local`
- Check that all environment variables are set

### Testing the SMTP Connection
You can test your SMTP settings using this simple script:

```javascript
// test-email.js
const nodemailer = require('nodemailer');
require('dotenv').config({ path: '.env.local' });

const transporter = nodemailer.createTransport({
  host: process.env.SMTP_HOST,
  port: parseInt(process.env.SMTP_PORT),
  secure: false,
  auth: {
    user: process.env.SMTP_USER,
    pass: process.env.SMTP_PASSWORD,
  },
});

transporter.verify((error, success) => {
  if (error) {
    console.log('❌ SMTP Error:', error);
  } else {
    console.log('✅ SMTP Server is ready to send emails');
  }
});
```

Run with: `node test-email.js`

## Security Notes

- Never commit `.env.local` to git (already in `.gitignore`)
- Use App Password, not your actual Gmail password
- Keep your credentials secure
- Consider rate limiting in production to prevent spam
- App Passwords can be revoked anytime from your Google Account

## Production Deployment

When deploying (Vercel, Netlify, etc.):
1. Add environment variables in your hosting platform's dashboard
2. Use the same variable names: `GMAIL_USER` and `GMAIL_APP_PASSWORD`
3. Make sure the Gmail account has 2FA enabled and App Password generated

## Alternative: Using a Different Email Service

If you prefer not to use Gmail, you can configure other SMTP services:

### SendGrid
```env
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASSWORD=your-sendgrid-api-key
```

### AWS SES
```env
SMTP_HOST=email-smtp.us-east-1.amazonaws.com
SMTP_PORT=587
SMTP_USER=your-ses-smtp-username
SMTP_PASSWORD=your-ses-smtp-password
```

Update the transporter configuration in `src/app/api/submit-application/route.ts` accordingly.
